# Installation

Run PolyPhoto-0.1.6-setup.exe for a per-user installation. Choose the installation folder and desktop / Start menu shortcuts. No separate .NET installation is required. Close PolyPhoto before installation. Existing PolyPDF, PolyWriter and PolySheet installations are independent.

Portable: extract PolyPhoto-0.1.6-win-x64.zip and run PolyPhoto/PolyPhoto.exe with the whole folder intact. In-app replacement is available for conventional installations. Portable copies can check releases but must be replaced manually while closed, or installed with setup.

Reinstall/update retains the registered installation location and shortcut choices and rejects downgrades. Uninstall through Windows installed apps or Uninstall.exe. Documents, settings and encrypted recovery in %LOCALAPPDATA%/PolyPhoto are preserved. Recovery remains bound to your Windows account and machine.

Windows x64, Windows 10 build 19041+ or Windows 11. Operating-system vendor support is separate from the application's minimum build requirement.
