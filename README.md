# PolyPhoto

![PolyPhoto](assets/polyphoto.png)

Version 0.2.8. A standalone local raster editor for Windows x64. English interface, light/dark themes, free and unlocked. No account, photo upload, subscription or activation.

[Download PolyPhoto for Windows](https://github.com/robertmartic/polyphoto/releases/latest). Choose the -setup.exe asset for installation or the -win-x64.zip asset for portable use. Official updates use this same public release channel.

File and operation commands use local vector icons. Raster tools stay in a vertical selector with a persistent active indicator. Narrow toolbars move commands into More; use Down to enter and Escape to close it. Tooltips include existing shortcuts and commands expose accessible names in both themes.

Create an image, or open a still PNG/JPEG as a new unsaved project. Save and Save as use the versioned .polyphoto format. Export creates a PNG/JPEG copy and does not mark the project saved. The original imported image is never automatically overwritten.

Raster layers with names, visibility, opacity and ordering; 8-bit channels, sRGB. Projects retain every layer, including hidden pixels. Format 1 projects remain readable; format 2 projects require PolyPhoto 0.1.5 or newer. Embedded ICC profiles are converted only after the import notice is accepted. Unsupported profiles stop import, with an explicit option to ignore the profile and assume sRGB. EXIF orientation is applied once. Other EXIF/IPTC/XMP metadata, including GPS, is not copied into projects/exports. PNG keeps transparency; JPEG uses the selected background and quality with lossy compression.

Limits: 24 million pixels; 16,384 pixels per side; 256 MiB input file; up to 16 layers within a 512 MiB padded pixel-storage limit; up to 16 document tabs per window within a shared 2 GiB pixel/history budget (not a process working-set cap). Unsupported: animation, CMYK, HDR, 16/32-bit channels, RAW, PSD, XCF and multi-page images. Undo retains changed pixel blocks and immutable selection masks within a 256 MiB history budget. Older history is removed when needed. Undo is not saved in projects.

Tools: rectangle, ellipse and freehand selections with New/Add/Subtract modes, invert and copy to a new layer; selection delete/crop; round brush/eraser with size, opacity and hardness; Clone Stamp; color picker/eyedropper, separate image/canvas resize, 90-degree rotations, flips and Tone adjustments (Brightness, Contrast, Shadows, Highlights). A completed stroke or applied operation is one Undo step. Selection changes can also be undone. Add, duplicate, rename, reorder, hide and remove layers in the Layers panel. Brush, eraser, selection delete and Tone adjustments affect the active layer. Image crop/resize/rotate/flip affect the entire stack. Import PNG/JPEG as a layer at the top left; pixels beyond the canvas are clipped. Transform layer opens an interactive canvas with Free Transform, independent width/height scaling, aspect lock, a movable pivot, skew, perspective/distort corners and a basic 3×3 Warp mesh. Drag handles or enter precise values. Changing the pivot keeps the image in place. Combine transformations in one preview; Apply clips off-canvas content and creates one Undo step; Cancel leaves the original unchanged. Choose bilinear interpolation for photos or nearest neighbour for pixel art. PNG/JPEG exports flatten visible layers with opacity. Moving selections, clipboard and text are planned separately.

Keyboard: Ctrl+N/O/S, Ctrl+Shift+S, Ctrl+Z/Y, Ctrl+A/D, Ctrl+Shift+I invert selection, Ctrl+J copy selection to a new layer, Delete; B brush, E eraser, M selection, S Clone Stamp, I eyedropper, H pan, V or Ctrl+T transform layer. Hold Space or use the middle mouse button to pan. Ctrl+wheel zooms. Fit follows window size; 100% maps image pixels to physical display pixels.

Recovery writes changed encrypted blocks after 30 seconds without edits. A busy operation postpones it. Recovery is tied to this Windows account and machine; it is not a backup. Restore opens an unsaved copy. Saving, or explicitly discarding/closing the document, removes its checkpoint. Edits since the last completed checkpoint can be lost.

See docs/INSTALLATION.md and docs/UPDATES.md. Software terms and third-party notices are included.

Tone adjustments previews all four controls on the active layer. Shadows targets darker tones and Highlights targets lighter tones; positive values lighten and negative values darken. Reset returns all controls to zero. Apply is one Undo step; Cancel leaves the project unchanged. Tooltips follow the current light/dark theme, including their text, background and border.

Selection shapes use pixel-center masks. Choose New/Add/Subtract in Tool options; Shift adds and Alt subtracts while dragging. Freehand closes on mouse release (maximum 8192 sampled points). Paint, erase, Clone Stamp, delete and Tone adjustments respect the active selection. Crop uses its bounding rectangle on the entire layer stack. An explicitly empty mask protects all pixels; Deselect resumes editing the whole active layer. Selections, clone anchors and Undo history are temporary editing state, excluded from projects and recovery. Pixel edits and all layers are saved and recovered as before.

Clone Stamp: choose S, Alt+click a source on the active layer, then paint. The source remains aligned across strokes. Each stroke samples an immutable snapshot of that layer, so overlapping cloning cannot feed its newly painted pixels back into the same stroke. Transparent or out-of-canvas source pixels leave the destination unchanged. A new document or a different active layer requires a source for that layer. Brush/eraser/clone show their actual image-pixel diameter and offer 0–100% hardness: 0% gives a soft feathered edge; 100% gives a hard edge. Opacity controls the strength/transparency of the stroke. Hardness is the inverse of the former Softness control (20% Softness = 80% Hardness), with the same resulting brush shape. The default is 100% Hardness, matching the previous 0% Softness default.

Open multiple PNG/JPEG images or .polyphoto projects in document tabs. Open supports multiple files; dropping multiple files and startup file arguments also use tabs. Each tab retains its layers, selection, Undo/Redo, saved state, zoom, pan, pixel preview and Clone Stamp source independently. Reopening an already-open project activates its tab. Imported images remain unsaved copies. Failed imports leave existing tabs intact.

Ctrl+Tab / Ctrl+Shift+Tab switch tabs; Ctrl+W closes the active tab. Ctrl+S and Save as apply to the active project; Save all (Ctrl+Alt+S) visits every modified tab. Closing the window or preparing an update checks unsaved work in every tab; Cancel keeps all tabs open. Background recovery checks all modified tabs, including inactive ones. Documents are not automatically reopened from a saved tab list; abandoned recovery copies are offered at startup.

Brush size, Hardness, Opacity, color and theme are remembered between launches. [ / ] or numpad − / + change brush size within 1–500 pixels. Text fields keep normal typing behavior. Tool options appear above Layers so the current tool controls remain easy to reach.

Transform workspace: choose Free Transform for corner/edge scaling and the round rotation handle; the gold cross sets the pivot. Skew uses side handles, Perspective uses four ordered corners and Warp uses nine mesh points. The coordinate editor follows the selected corner/node. Positive rotation is clockwise. Shift constrains proportions or rotation; arrows nudge the image or selected control. Ctrl+wheel zooms the workspace; Fit canvas / Fit handles restore useful views. All transformations affect the entire active layer, independent of a pixel selection. Bilinear interpolation is alpha aware; nearest neighbour suits pixel art.

Keep perspective corners and Warp cells convex, without crossing or collapsing their edges. Invalid settings disable Apply and show a reason. Transformations stay temporary until Apply; applied results are raster pixels and the project format remains unchanged. Other tabs and editing commands are locked while the workspace is open; background recovery retains the original document state.
