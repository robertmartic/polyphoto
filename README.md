# PolyPhoto

PolyPhoto 0.5.0 is a native Windows x64 photo editor with a neutral canvas, a vertical tool strip, and a Layers inspector. The English interface supports light and dark themes. Editing is local and free.

[Download the Windows installer](https://downloads.polystudio.tools/polyphoto/0.5.0/PolyPhoto-0.5.0-setup.exe) or [the portable ZIP](https://downloads.polystudio.tools/polyphoto/0.5.0/PolyPhoto-0.5.0-win-x64.zip).

Open still PNG/JPEG images and existing .polyphoto projects in separate tabs. Save projects to retain layers, masks, and editable adjustments. Export visible layers as PNG or JPEG. The original imported photo remains available.

Use selection and crop, Brush, Eraser, Clone Stamp, Paint Bucket, a color wheel, and layer transformations. Tone can create an editable adjustment layer or change the selected raster layer's pixels. Levels, Curves, Hue / Saturation and Color Balance are also available as adjustment layers. Choose Help or press F1 for the offline guide.
