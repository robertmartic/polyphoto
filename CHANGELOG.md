# PolyPhoto changelog

## 0.2.0

- Select with rectangles, ellipses or freehand shapes; add, subtract, invert and copy selected pixels to a new layer.
- Keep painting, erasing, deletion, cloning and Tone adjustments inside the active selection.
- Retouch with Clone Stamp using an aligned source and stable per-stroke sampling.
- Set brush and eraser softness and see the brush diameter directly on the canvas.
- Undo, redo or cancel complete selection gestures and retouch strokes.
- Reduce allocations while composing layers and refreshing the canvas, with bounded selection/history storage.
- Continue opening existing projects and recovering every layer after interrupted sessions.

## 0.1.6

- Add Shadows and Highlights alongside Brightness and Contrast in the renamed Tone adjustments window.
- Preview all four adjustments together on the active layer, reset their values, apply as one Undo step or cancel.
- Keep tooltip text and backgrounds readable in the dark theme and when switching themes.

## 0.1.5

- Work with raster layers: add, duplicate, rename, reorder, hide, change opacity and remove layers.
- Import PNG or JPEG images as new layers.
- Preview active-layer movement, scaling, rotation and mirroring before applying or cancelling.
- Paint, erase and adjust the active layer; export the visible composition as PNG or JPEG.
- Save and recover complete layered projects, including hidden pixels, while continuing to open older projects.
- Undo and redo layer edits and transformations within the existing history budget.

## 0.1.2

- Use clear vector icons for file, image, adjustment and view commands.
- Keep raster tools in a vertical selector with a persistent active indicator.
- Access commands through More when toolbar space is limited.
- Navigate named controls and overflow menus with the keyboard in light and dark themes.
- Rotation and mirroring commands now complete reliably.

## 0.1.1

- Added optional PolyHUB integration for coordinated updates while preserving application save prompts.
- Coordinated setup, uninstall and update locking.



## 0.1.0
- Create and edit local images in a single raster layer.
- Save editable .polyphoto projects and export PNG or JPEG copies.
- Crop, resize images and canvases, rotate, flip, paint and erase with Undo/Redo.
- Adjust brightness and contrast with a preview.
- Use light/dark themes, encrypted local recovery and in-app updates.
