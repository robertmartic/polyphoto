# Changelog

## 0.1.0
- Create and edit local images in a single raster layer.
- Save editable .polyphoto projects and export PNG or JPEG copies.
- Crop, resize images and canvases, rotate, flip, paint and erase with Undo/Redo.
- Adjust brightness and contrast with a preview.
- Use light/dark themes, encrypted local recovery and in-app updates.
